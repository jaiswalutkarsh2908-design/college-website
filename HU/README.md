## 📌 Project Overview

This project is a complete architectural and UI/UX modernization of the university web presence for **Haridwar University, Roorkee** (Uttarakhand). It bridges high-speed semantic HTML5, modern vanilla CSS3 design systems (custom properties, flexbox, CSS grid, glassmorphism), and vanilla JavaScript to deliver a lightweight, high-performance web experience across desktop, tablet, and mobile devices without any external heavy framework dependencies.

### 🎯 Key Objectives Achieved:
1. **Modern Visual Identity:** Harmonized with Haridwar University's authentic blue, emerald, and gold academic colors.
2. **True 100% Mobile Responsiveness:** Custom animated slide-down navigation drawer, tap-outside auto-close, touch-sized buttons, and iOS Safari input auto-zoom prevention.
3. **Verified Placement Architecture:** Highlighting national ranking (#37 by Times of India), highest package (₹85 LPA), and corporate recruiter showcases.
4. **Zero-Dependency Lightweight Build:** Ultra-fast load times with zero third-party framework overhead (No bloated jQuery, Bootstrap, or React required).

## 🛠️ Technology Stack & Architecture

- **Markup:** Semantic HTML5 with proper ARIA accessibility tags and OpenGraph meta descriptions.
- **Styling:** Modern CSS3
  - CSS Custom Properties (Variables) for theme consistency
  - CSS Grid & Flexbox for multi-directional responsive layouts
  - Responsive Typography with `clamp()`
  - Glassmorphism & subtle micro-interactions
- **Scripting:** Vanilla JavaScript (ES6+)
  - Mobile hamburger toggle with event propagation control
  - Tap-outside event listener for intuitive mobile menu dismissal
  - Scroll-aware floating "Back to Top" trigger
  - Form validation and submission alert handling
- **Assets:** Official high-resolution assets locally bundled in `images/` for instant offline and online availability.

## 🚀 How to Run Locally

No package managers, Node.js, or complex build setups required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/haridwar-university-concept.git
   cd haridwar-university-concept
   ```

2. **Open directly in any modern web browser:**
   - Double click `index.html` (or right-click ➔ Open With ➔ Chrome / Edge / Firefox / Safari).
   - Alternatively, serve via VS Code Live Server or Python HTTP:
     ```bash
     python -m http.server 8000
     ```
   - Navigate to `http://localhost:8000/` in your browser.
